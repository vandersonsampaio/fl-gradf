# Result — B3.0: BloodMNIST sanity check on the official AdaAggRL

**Date:** 2026-10-05. Rules fixed in `results/b31_medmnist_oficial/PREREGISTRO.md` §3 (commit `315b880`; English translation in `PREREGISTRO.en.md`), before any run. Code and artifacts with hashes in `CODIGO.sha256`.

**Grid:** 12 uniform-FedAvg runs, 500 rounds, seeds 130–132 (BloodMNIST without attack, LMP and EB; MNIST without attack), from 10/04 12:29 to 10/05 17:26, with a pause from 07:00 to 16:29 on 10/05. No failures.

## Mechanical application of the rules (`analisar_b30.py` → `analise.txt`)

| condition | T per seed (median 401–500) | mean | resets |
|---|---|---|---|
| BloodMNIST, no attack | 77.39 / 77.83 / 78.26% | **77.83%** | 0 / 0 / 0 |
| BloodMNIST, LMP | 23.75 / 19.55 / 19.60% | 20.97% | 108 / 101 / 113 |
| BloodMNIST, EB | 21.79 / 7.13 / 22.29% | 17.07% | 113 / 14 / 114 |
| MNIST, no attack | 96.84 / 96.85 / 97.05% | **96.92%** | 0 / 0 / 0 |

- **Convergence: CONVERGES.** T_Blood = 77.8% (≥ 50%) and mean 451–500 − 401–450 = **+1.79 p.p.** (< 2). **Borderline:** the curve is still rising slowly at the end of the run.
- **Attack inclusion: LMP and EB ARE INCLUDED.** FedAvg drops 56.9 p.p. under LMP and 60.8 p.p. under EB (threshold: 5 p.p.). Without a defense, both attacks drive the official environment into reset cascades (~100 per run).
- **Margin:** M = 1.0 × (100 − 77.83) / (100 − 96.92) = 7.19 p.p. → **M = 3.00 p.p.** by the rule's cap. By the pre-registration, it is a **weak equivalence**.

**Decision (pre-registration rule):** B3.1 with attacks **LMP and EB** and margin **±3.00 p.p.**
